# Nädal 5: Visualiseerimise disain – Power BI CEO Dashboard

## Roll: A

## Eesmärk

Selle nädala eesmärk oli õppida, kuidas kujundada andmete põhjal juhtimisvaadet ning valida sobivad visualiseeringud äriliste küsimuste selgitamiseks. Fookuses oli Power BI abil CEO Dashboardi loomine.

## Tegevused

- Disainisin Power BI abil CEO Dashboardi.
- Lõin KPI kaardid olulisemate ärinäitajate kuvamiseks.
- Koostasin joondiagrammi müügitulu muutuse visualiseerimiseks kuude lõikes.
- Harjutasin dashboardi visuaalse ülesehituse planeerimist.
- Mõtlesin läbi, millised näitajad on juhtkonna jaoks kõige olulisemad.
- Osalesin meeskonna andmemaastiku ja ühise väljundi täiendamisel.

## Kasutatud tööriistad

| Tööriist | Kasutus |
|---|---|
| Power BI | Dashboardi loomine ja visualiseerimine |
| SQL / andmestik | Andmete ettevalmistamine ja analüüsi alus |
| Google Slides | Meeskonnatöö tulemuste esitlemine |
| Markdown | README dokumentatsiooni vormistamine |

## Loodud visualiseeringud

- KPI kaardid olulisemate mõõdikute kuvamiseks.
- Joondiagramm müügitulu muutuse jälgimiseks kuude lõikes.
- Juhtimisvaade, mis annab kiire ülevaate ettevõtte tulemustest.
- Dashboardi struktuur, mis toetab kiiret otsustamist.

## Peamised õppetunnid

- Õppisin valima sobivaid diagrammitüüpe vastavalt äriküsimusele.
- Sain aru, et dashboard peab olema lihtne, loetav ja suunatud konkreetsele sihtrühmale.
- Harjutasin KPI kaartide kasutamist juhtimisvaate loomisel.
- Mõistsin, et visualiseerimise eesmärk ei ole ainult andmeid näidata, vaid aidata neist kiiresti aru saada.
- Sain praktilise kogemuse Power BI dashboardi kujundamisel.

## Andmeanalüüsi tähelepanekud

CEO Dashboardi loomisel oli oluline keskenduda kõrgetasemelistele mõõdikutele, mis annavad kiire ülevaate ettevõtte tulemuslikkusest. Juhtimisvaates on oluline vältida liigset detailsust ning tuua esile peamised trendid, muutused ja probleemkohad.
