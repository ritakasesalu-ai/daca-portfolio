# Nädal 0: Onboarding ja töökeskkondade seadistamine

## Eesmärk

Selle nädala eesmärk oli seadistada projekti jaoks vajalikud töövahendid, tutvuda UrbanStyle'i andmestiku ja äriprobleemiga ning luua alus edasiseks meeskonnatööks.

## Tegevused

- Seadistasin vajalikud töökeskkonnad:
  - GitHub
  - Supabase
  - NotebookLM
- Tutvusin UrbanStyle'i lähteülesande ja olemasoleva andmekaosega.
- Osalesin meeskonnatöö esmases korraldamises.
- Seadistasin grupitöö jaoks NotebookLM keskkonna, et koondada õppematerjalid ja toetada projektiinfost arusaamist.
- Tutvusin projekti GitHubi repositooriumi ja meeskonna töökorraldusega.

## Peamised õppetunnid

- GitHub aitab hoida projekti failid, dokumentatsiooni ja tööversioonid struktureeritult ühes kohas.
- Supabase võimaldab hallata andmebaasi ja töötada andmetega pilvepõhiselt.
- NotebookLM on kasulik tööriist õppematerjalide kokkuvõtmiseks, info struktureerimiseks ja materjalide põhjal küsimustele vastamiseks.
- Projekti alguses on oluline kokku leppida töökorraldus, vastutusalad ja failide struktuur, et meeskonnatöö oleks hiljem sujuvam.

## Kasutatud tööriistad

| Tööriist | Kasutus |
|---|---|
| GitHub | Projekti failide ja dokumentatsiooni haldamine |
| Supabase | Andmebaasi seadistamine ja andmete haldamine |
| NotebookLM | Õppematerjalide ja projektiinfo struktureerimine |
| Markdown | README dokumentatsiooni vormistamine |
